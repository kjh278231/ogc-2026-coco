멀티스레드/병렬 구간 맵

4 CP-SAT workers 제출 default recombine

submission/solver.py::_recombine에서 OR-Tools CP-SAT이 기본 4 search workers로 돈다.

N processes x 1 portfolio worker pool

multiprocessing spawn으로 profile별 worker를 동시에 실행한다. 각 worker의 CP-SAT은 1 worker로 제한한다.

single-thread loop assignment search

improved_search, _climb, local_search, _perturb는 worker process 내부에서 순차 실행된다.

native JIT Numba kernels

AABB candidate scan, mask overlap 등은 JIT로 빨라지지만 현재 구조도상 명시적 multi-thread 영역은 아니다. portfolio에서는 NUMBA_NUM_THREADS=1로 제한한다.

최신 병렬화의 핵심은 한 worker 안에서 thread를 늘리는 방식이 아니라, 서로 다른 seed/profile의 독립 search trajectory를 여러 process로 동시에 실행하고 master가 최종 후보를 같은 기준으로 평가하는 방식이다.

코드 기준 요약

제출 default는 아직 portfolio가 아님

submission/myalgorithm.py는 solver.framework_solve(prob, timelimit)만 호출한다. portfolio wrapper는 제출 엔트리에 연결되어 있지 않다.

최신 변경은 baseline solver 쪽

baseline/solver.py는 _return_assignment, SOLVER_SEED, SOLVER_SWAP guided swap, worker mode reserve 생략을 포함한다.

병렬 oversubscription 방지

portfolio에서는 worker가 여러 개라 SOLVER_CP_WORKERS=1, OMP/MKL/OPENBLAS/NUMBA_NUM_THREADS=1을 강제로 설정한다.
